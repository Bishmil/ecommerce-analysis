# Анализ пользователей интернет-магазина 

Данные для анализа взяты с Kaggle: [E-Commerce Behavior Data from Multi-Category Store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store/data?select=2019-Oct.csv).  
Для проекта использована только неделя с 7 по 13 октября 2019 года, чтобы уменьшить размер файла.  
Файл локально находится в папке `data/` и **не загружается в репозиторий**, чтобы не превышать лимит GitHub по размеру файлов.

В этом проекте я исследовал, как ведут себя пользователи интернет-магазина за неделю. Хотел понять, кто как двигается по воронке продаж, какие товары и бренды приносят больше всего денег, когда люди заходят на сайт и кто из них самые ценные покупатели.

За неделю сайт посетили больше миллиона человек, которые сделали около двух миллионов сессий. Основные пики активности - утром (8-9 часов) и днём (15-16 часов). Интересно, что вечером заходов меньше, но средний чек выше. Значит те, кто приходит вечером, тратят больше за один раз.

Конверсия просмотра товаров в добавление в корзину оказалась низкой - всего 5.9%. А вот конверсия в покупку выше 100%, скорее всего из-за кнопки «Buy now» или потому что часть товаров была добавлена до недели анализа.

Наибольший доход приносят смартфоны, особенно Apple - на них приходится почти половина всей выручки. При этом 1% самых активных пользователей с 6 и более заказами дают около 15% всего дохода.

Что из этого следует: стоит поработать над конверсией добавления в корзину, следить за суперпокупателями и планировать маркетинговые активности на утренние пики. Основной доход даёт техника - смартфоны и популярные бренды типа Apple.

Проект выполнен с использованием Python, pandas, numpy, matplotlib, seaborn и Jupyter Notebook.
